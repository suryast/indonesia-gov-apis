## Checker changes

- **Content checks (`EXPECT` in `check.py`):** for listed IDs the response body must contain the expected text (case-insensitive). A 2xx/3xx without it is reported as the new status **`degraded`**, shown in its own summary card on the status page.
- **Tier names** added for tiers 8–11.
- **Probe label:** when run in GitHub Actions the probe is labelled "GitHub Actions (US)" instead of "Sydney, Australia". Copy that said the page was checked "from US + Jakarta via SOCKS5" is now generic, and notes that the Jakarta probe is offline.

## Not done yet

- **Freshness checks:** BGN ("data per …"), SIKD ("data diterima SIKD per …"), SIPP ("Pembaharuan Data : …") and the BMKG forecast all print a timestamp. Parsing it would catch silently stale data; this update only checks that the text is present.
- **API-key checks:** INAPROC v1, the Bapanas WebAPI and BPS need tokens. Only their public docs and landing pages are monitored.
- **Tier 2/3 candidates** (LPSE instances, JISDOR, Bapanas WebAPI/catalogue, Bawaslu Satu Data, e-LHKPN e-Announcement, PDDikti, Kaltim/Semarang/DPD CKAN, Sirekap) are not added yet.
- Personal-data lookups (Cek Bansos, NISN, PDDikti) are only checked at the root page. Never automate queries against them.
