Status Legend
Up — Portal responding normally
Mixed / legacy geo label — Unequal probe observations; cause unknown

Down — Portal unreachable or erroring
DNS error — Probe could not resolve the host; not proof of permanent failure
Spark bars — Daily history, one bar per day
Degraded means a complete bounded response lacked its configured public marker; it is a heuristic, not an API correctness claim. Unverified content checks retain HTTP status. Transport errors distinguish DNS, timeout, TLS, network, proxy and redirect failures. HTTP responses do not establish API correctness or access rights. Unequal reachability does not establish geographic blocking. Sources and check time are taken from the selected snapshot.
